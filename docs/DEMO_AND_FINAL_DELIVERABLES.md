# Demo and Final Deliverables

## Suggested 12–15 minute demo
1. Business problem/scope.
2. Sign in and inspect dashboard.
3. Ingest public/synthetic text and a document; review extraction.
4. Generate stories, criteria and linked tests.
5. Generate/validate OpenAPI, architecture recommendation and sprint plan.
6. Show prompt versioning and baseline evaluation.
7. Ask assistant question and export artifacts/ZIP.
8. Present measured outcomes, security boundaries and limitations.

Only demonstrate features that actually work; do not present placeholders as implemented.

## Evidence checklist
- [ ] Commit/tag and reproducible setup.
- [ ] UC-01–UC-14 and SC-1–SC-15 matrix with evidence/status.
- [ ] Unit coverage, integration/E2E and defect reports.
- [ ] OpenAPI/export validation.
- [ ] Security/dependency scan and RBAC denial tests.
- [ ] Accessibility/performance measurements.
- [ ] Prompt inventory and regression report.
- [ ] Evaluation dataset, baseline provenance, formulas, sample counts and results.
- [ ] Case study and manual-vs-assisted time protocol.
- [ ] CI build/test/scan/package/deploy/smoke evidence.
- [ ] Backup/restore and runbook evidence.
- [ ] Final report, presentation, video, user/admin/prompt guides.

## Report structure
Problem/objectives; scope; architecture/ADRs; implementation; AI pipeline/prompts; security/privacy; testing; evaluation and case study; performance/effort results; limitations; lessons and future work.

Disclose baseline incompleteness, subjective metrics, model variance, unsupported claims, provider cost/latency, small samples, parser/OCR limitations and excluded production integrations.
