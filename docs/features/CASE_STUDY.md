# Open-Source Case Study

**Traceability:** UC-10, FR-10, SC-10, TO-9.

Choose a publicly documented open-source project with a compatible license, sufficient requirements/baselines and feasible scope. Record project URL, license, commit/tag, access date and selected scope. Use no proprietary or confidential data.

## Procedure
1. Select public requirements and human-authored baseline artifacts.
2. Record source paths, versions and provenance.
3. Ingest and manually confirm extracted requirements.
4. Generate stories, criteria, tests, API specs, architecture recommendations and estimates.
5. Preserve prompts, provider/model, configuration, retrieval IDs, outputs and validation.
6. Compare outputs against baseline with the versioned evaluation method.
7. Time comparable manual and assisted tasks to measure effort reduction.
8. Document quantitative results, failures, examples, lessons and limitations.

## Report
Executive summary; project/license; scope/data; baseline construction; prompts/model; metric formulas; results by artifact type; time comparison; hallucination/failure analysis; reviewer feedback; threats to validity; lessons and limitations.

**Acceptance:** end-to-end run is reproducible; baselines and generated versions are identifiable; metrics include sample counts/method; no results are fabricated; license constraints are respected.
